CSC2103 Group Project - Source Code Repository
===============================================

GitHub repository (accessible to the lecturer):
https://github.com/yijay-k/kenny-DNA

The repository contains:
  - problem1_activity_selection.py : Greedy
  - problem2_coin_change.py        : Dynamic Programming
  - problem3_tsp_heuristic.py      : Heuristic
  - main.py                        : optional menu launcher for all three
  - ui.py                          : shared terminal UI + input helpers
  - samples/                       : sample inputs and captured outputs
  - README.md                      : instructions to run the programs

To run (any one problem, or the menu):
  python3 problem1_activity_selection.py
  python3 problem2_coin_change.py
  python3 problem3_tsp_heuristic.py
  python3 main.py
